# 👕 EL CAMERINO - Tienda Deportiva y Zapatillas de Futsal

> *"Donde empieza el partido: todo tu equipamiento de pies a cabeza."*

Plataforma e-commerce moderna, rápida y totalmente responsive para venta de calzado de fútbol sala, medias antideslizantes, uniformes y accesorios deportivos.

---

## 🚀 Categorías de Productos
1. **👟 Zapatillas de Futsal:** Joma Top Flex Rebound, Nike Mercurial Vapor, Adidas Predator Elite Sala, Puma Future Indoor.
2. **🧦 Medias y Antideslizantes:** Medias técnicas Pro Grip con silicona antiderrapante, medias altas oficiales y tobilleras de compresión.
3. **👕 Uniformes y Ropa Deportiva:** Conjuntos completos de juego (camiseta + short), camisetas Dry-Fit de entrenamiento y petos tácticos.
4. **⚽ Balones y Equipamiento:** Balones reglamentarios con rebote controlado para futsal, espinilleras de fibra de carbono, guantes de arquero y mochilas con compartimento para calzado.

---

## ✨ Características Principales
* **Catálogo interactivo con filtros instantáneos:** Filtrado por categoría y barra de búsqueda en tiempo real.
* **Carrito de compras persistente:** Carrito interactivo con almacenamiento en `localStorage`, cálculo automático de subtotal, costo de envío y total.
* **Modales accesibles nativos `<dialog>`:** Implementados siguiendo las mejores prácticas de *Modern Web Guidance* (`closedby="any"`, `overscroll-behavior: contain`, light-dismiss y foco accesible).
* **Vista Rápida (Quick View):** Modal con detalle técnico, selección de tallas y selector dinámico de cantidad.
* **Checkout completo:** Formulario con validación de datos del cliente, método de pago (contraentrega, transferencia directa, tarjeta) y generación de enlace para despacho vía **WhatsApp**.
* **Diseño Responsive Moderno:** Optimizado con CSS Grid, Flexbox y temas oscuros con acentos deportivos neón para móviles, tablets y monitores.

---

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Semántica pura, `<dialog>` nativo, formularios accesibles.
* **CSS3:** Variables CSS (Custom Properties), Flexbox, CSS Grid, media queries responsivas, backdrop-filter.
* **JavaScript (Vanilla ES6+):** Programación modular sin dependencias externas pesadas.

---

## 💻 Cómo Ejecutar
Basta con abrir el archivo `ejercicio/index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).
